# Rosso — エフェクター・オーディオ専用 回路図シミュレーター

ギターエフェクターや真空管アンプの自作で使う**マニアックな部品を1920点**収録した回路図シミュレーターです。回路を描くと、その場で音が出ます。

**→ [紹介ページ](https://tsukuba-onkyo.github.io/Rosso-dist/)** ・ **[ダウンロード](../../releases/latest)**

## 何が違うのか

EQカーブの模倣ではなく、**修正節点解析 (MNA) + Newton法**で回路をサンプル単位に解いています。そのため部品の「劣悪な物理特性」がそのまま音に出ます。

- **ゲルマニウムTr 180種** — 漏れ電流が10°Cごとに倍増。真夏にファズが死ぬ挙動まで再現
- **真空管 188種** — グリッド電流による非対称圧縮、結合コンデンサへの電荷蓄積 (ブロッキング)
- **BBD素子 33種** — 実際のバケツリレー動作。段数ぶんの電荷転送損失で音が曇る
- **CdSセル** — 光源をLEDか白熱球から選べる。電球は熱容量で鈍り、加熱より冷却が遅い
- **トランス** — 磁気飽和と残留磁束

回路図の写真を読み込んで回路に起こす機能、AIと会話しながら回路を育てる機能もあります (Google AI Studio の無料APIキーが必要です)。

| `Rosso_x.y.z_x64-setup.exe` | Windows 64bit (インストーラ・推奨) |
| `Rosso_x.y.z_x64_en-US.msi` | Windows 64bit (MSI) |

新しい版が出ると、アプリが起動時に更新を案内します。

### 初回起動時の警告について

インストーラにコード署名を行っていないため、macOS では Gatekeeper、Windows では SmartScreen の警告が出ます。macOS は右クリック →「開く」、Windows は「詳細情報」→「実行」で起動できます。

## 既知の制限

- **アンプシミュレーターは現在無効です。** 真空管2段のモデルで断続的なノイズが出る不具合の原因は特定済みで、修正でき次第あらためて有効にします
- シミュレーションは挙動の近似です。実機の製作・改造は自己責任でお願いします。特に真空管回路の高電圧は危険です
